## 🌟 Overview

Python AI Toolkit CLI is a modern command-line application that brings advanced AI capabilities directly to your terminal. Whether you're summarizing lengthy documents, translating text between languages, or analyzing sentiment, the toolkit provides a fast, elegant, and developer-friendly experience.

Designed with simplicity and performance in mind, it combines powerful AI features with a beautiful terminal interface.

---

## ✨ Key Features

### 📝 AI Text Summarization

Generate concise summaries from articles, reports, notes, and long-form content.

### 🌐 Multi-Language Translation

Translate text between multiple languages with high accuracy.

### 😊 Sentiment Analysis

Detect emotional tone and classify text as positive, negative, or neutral.

### 🎨 Beautiful Terminal Experience

Clean, colorful, and easy-to-read terminal output powered by Rich.

### 📂 File Processing Support

Analyze and process content directly from TXT, Markdown, and other text files.

### 🔄 Interactive CLI Mode

Engage with AI through an interactive conversational terminal interface.

### 📊 Usage Analytics

Track token usage and processing statistics for each request.

### 📄 Multiple Export Formats

Save results in JSON, Markdown, or plain text formats.

### ⚡ Fast & Lightweight

Optimized for speed with minimal resource consumption.

```bash

cd python-ai-toolkit-cli

pip install -r requirements.txt
```

## 🔑 Configuration

Create a .env file:

```env
OPENAI_API_KEY=your_api_key_here
```

## 🎯 Example Commands

### Summarize Text

```bash
python ai_toolkit.py summarize document.txt
```

### Translate Text

```bash
python ai_toolkit.py translate --to french "Hello World"
```

### Analyze Sentiment

```bash
python ai_toolkit.py sentiment review.txt
```
